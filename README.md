# Kanishka's-Power-BI-Dashboard-Portfolio


> A collection of interactive Power BI dashboards built to solve real-world business problems using Business Intelligence, Data Visualization, and KPI-driven analytics.

This repository showcases my end-to-end dashboarding projects developed using **Power BI**, **SQL**, **Excel**, **Python**, **DAX**, and **Power Query**. Each dashboard focuses on solving a unique business problem by transforming raw data into actionable insights for stakeholders.
